# 魔女の旅々 · Android 手绘播放器

独立原生 Android 工程，固定两个曲目槽位：

| 曲名 | 歌手 |
| --- | --- |
| 灰色のサーガ | ChouCho |
| リテラチュア | 上田麗奈 |

不附带歌曲录音。点按画面中的曲名打开固定歌单，为每首歌导入对应的本地音频。支持 MP3、M4A、FLAC、WAV、OGG，以 Android 实际解码能力为准。导入时验证文件包含可解码音频，再保存到应用私有目录；原始文件之后移走不影响播放。替换失败保留原音频。卸载或清除应用数据会删除已导入音频。

## 操作

- 点按曲名或长按插画：歌单与导入入口。
- 中间手绘三角：播放/暂停。
- 左右手绘箭头：在两首曲目之间循环切换。
- 上方细线：拖动播放进度，进度线从人物腿后穿过。
- 下方细线：播放音量；点按左侧小喇叭静音/恢复。
- 播放完毕自动播放另一首已导入的歌曲；另一首没有音频则停下。
- 支持后台播放、系统媒体通知、锁屏媒体控制与耳机断开暂停。音量和当前曲目会保存。
- 不需要联网或广泛存储权限；文件由 Android 系统文件选择器授权读取。

当前版本为 **1.6**：使用 Yuji Boku 毛笔字库、修复后的整个人物与完整头部表情区域。详细变更见文末；以下带版本号小节保留历史说明。

## 1.1 字体与动画

曲名、时间、歌单和应用提示统一使用随包提供的 Yomogi 手写字体（历史版本使用 SIL Open Font License；1.6 已替换，当前许可见 assets/fonts/YujiBoku-OFL.txt），不再把一个曲名作为图片、另一个用衬线字体拼接。

人物透明层 `elaina-layer.png` 与天空层 `player-sky.png` 分别由图像工具从参考画面生成。播放时，只对人物进行轻微摇摆、上下律动和局部网格变形，使帽檐、头发和裙摆产生随动；暂停后阻尼回到静止。天空和操作控件不随人物运动。页面不可见时不继续请求动画帧。

升级使用同一应用 ID 和本地签名、版本号 1.1，可直接覆盖安装以保留导入的音频。

## 图像

`player-reference.jpg` 为用户提供的第二张参考图。`player-clean.png` 通过图像生成工具移除参考图中的静态文字、按键和滑杆，作为早期版本背景保留；1.1 使用分离的人物透明层和天空层；原图中的上一首、下一首与喇叭图形仍直接复用，所有文字统一使用随包字体。图片承担主要视觉，原生透明按钮和滑杆提供操作与无障碍语义。不同屏幕按参考画面比例居中完整显示，不裁切人物。

生成修复会有少量笔触差异，因此不宣称逐像素一致。

## 构建

标准工程：Android Studio 打开本目录，使用 Android SDK 36、Build Tools 36.0.0、JDK 17+。

```sh
./gradlew assembleDebug
```

当前云环境提供 Java 编译器模块但没有 `javac` 命令，因此另附无需 Gradle 下载的 SDK 原生构建脚本：

```sh
ANDROID_HOME=/path/to/android-sdk ./tools/build.sh
```

SDK 默认路径为 `$HOME/.cache/android-cloud/sdk`。依赖 Java 的 `jdk.compiler`、`jdk.jartool` 模块、Python 3、`keytool` 及 Android Build Tools。输出为 `app/build/manual/witch-player.apk`，仅使用本地调试签名。

## Android 16 验证

测试源码位于 `app/src/androidTest`，仅在显式设置 `WITCH_TEST_BUILD=1` 时打入测试 APK；交付 APK 不含测试入口及测试音频。

```sh
WITCH_TEST_BUILD=1 ./tools/build.sh
adb install --no-incremental -r app/build/test-manual/witch-player.apk
adb shell pm grant com.wanderingwitch.player android.permission.POST_NOTIFICATIONS
adb shell am instrument -w com.wanderingwitch.player/.PlayerIntegrationTest
```

测试在设备内临时生成正弦波音频，覆盖导入处理、播放按钮、暂停、切歌、跳转、应用音量、后台播放、耳机断开暂停。测试不会验证用户导入的录音内容是否确为指定歌曲。

## 1.2 修正

取消 1.1 中对整个人物的网格变形、摇摆和浮动。脸、躯干和腿保持固定；独立裁分的左右发束、帽尖和外侧衣摆仅作小幅刚性转动，像分层动态壁纸的风动效果，纹理不会被逐点拉伸。这不是完整的 Live2D 表情、转头或骨骼动作模型。

曲名使用同一字体加粗，并增加黑色描边；时间数字同步加粗并改用更深的颜色。限定曲名宽度以避免被人物遮住。

## 1.3 表情与音乐动作

- 使用图像生成制作的睁眼 / 半闭眼 / 闭眼表情图集，眼部与原画对齐；播放时约 240 ms 合眼，暂停时约 240 ms 睁眼。
- 人物整体以保持笔触不变的平移和转动轻轻摇摆，发束、帽尖和衣摆有滞后随动；没有网格扭曲。开始与停止使用阻尼，快速切换也不瞬间跳姿态。
- 在后台线程本地解码当前音频，以 25 ms 窗口计算 RMS 能量，并从能量起伏估计节拍。播放位置用于读取相应时刻的数据，动作强度平滑跟随音乐强弱。
- 节拍是估计值，不保证每首歌的每一拍都准确；分析准备期间或解码器无法分析的音频，仍能播放并使用柔和的基础摇摆。
- 不使用麦克风、录音权限、外部歌曲服务或网络上传。分析结果只在当前进程中缓存，导入文件变化会重新分析。
- 保留 1.2 的加粗字重和统一字体。版本 1.3 可直接覆盖安装以保留导入音频。

## 1.4 表情与错位修正

- 保留原画的头部轮廓、帽子和颈部，取消替换整套头帽素材及独立转头；避免素材比例不同造成错位。图像生成的三种表情仅绘制在原脸部范围内，平静微笑替代原张嘴表情，播放闭眼、暂停睁眼，约 320 ms 连续切换。
- 脚部固定，以躯干缓慢重心摆动和小幅呼吸替代整张人物平移；头帽随躯干一起移动，发束、帽尖和衣摆有轻微滞后。开始和暂停使用连续速度的阻尼过渡。
- 音频能量与估计节拍继续控制动作；保留统一加粗字体、固定双曲目导入和后台播放。
- 可覆盖安装旧版，保留已导入音频。动态为分层画作动作，不是完整 Live2D 模型。

## 1.4.1 睁眼表情修正

重新以原画生成柔和睁眼、小幅闭嘴微笑的表情，原脸部坐标直接对应，保留头帽位置。扩大眼角周围的有效绘制范围，避免旧裁切路径压住眼角。删除过渡中半睁眼帧的显示，睁眼与闭眼图像平滑交替，保留播放/暂停行为及原动作。

## 1.5 连续动作

- 躯干、发梢、帽尖与衣摆分别使用阻尼状态与速度；暂停继续完成回落，快速播放/暂停也不重置姿势。
- 节拍变化逐渐改变摆动速度；发梢与衣摆响应躯干速度，并混合幅度很小的慢风，降低机械同步。音乐分析得到的能量较低时，身体动作也会减小。
- 屏幕可见时按显示刷新同步绘制；完全静止后停止请求动画帧。实际帧率取决于设备。脚部固定，头帽仍是原画整体，不单独拼接。
- 闭眼素材以柔和睁眼原图重新生成，运行时只覆盖眼部，嘴角与脸型不随播放切换；合眼约 180 ms，睁眼约 260 ms。
- 可通过 `./tools/check-motion.sh` 检查动作范围、速度连续性、完全回落、不同帧率一致性与快速切换。
- CPPlayer 调研见 `docs/CPPLAYER-ASSESSMENT.md`；尚未接入，当前仍是固定两首的本地导入播放器。
