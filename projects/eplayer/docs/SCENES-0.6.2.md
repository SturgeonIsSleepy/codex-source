# ePlayer 0.6.2

详情页具有独立 instanceId，网络刷新保留 ID，重新打开生成新 ID。详情窗口和组合内容按场景键隔离，栈内每页单独保留滚动状态；返回先清零手势变换，再提交路由，避免子页的布局、动画和滚动信息带回父页。移除每次返回后的异步强制滚到顶部。

设置采用真实路径栈，头像→设置→音源/关于返回到设置，设置再返回头像菜单；重复点击不重复压栈。播放设置、画面设置及其内部页面仍逐层关闭。

搜索图标一次进入独立窗口，顶部输入框自动获得焦点和键盘；输入经过 200 ms 防抖请求已核实的 search/suggest（mobile），显示关键词联想。失败仅回退本机最近听过的匹配歌曲名；提交后隐藏键盘，展示同一页的歌曲/歌单/专辑/歌手结果。手势返回仍先关闭输入法。

播放器使用一条连续滚动列表：顶部收起/更多，大封面和原有伊蕾娜，曲名/歌手，喜欢/不感兴趣/歌词/评论/音质，进度与五键控制，再到来源与播放队列。上滑即隐藏/暂停角色，队列滚入时固定小封面、曲名和上一首/播放/下一首。保留拖动、多选、全选和移除；远程同源队列可显式保存成私密网易歌单。不捏造点赞数量或 YouTube 数据；不感兴趣是本机对后续漫游的过滤。

歌词移除上一版封面坐标放大和 GPU 模糊开场，改为 220 ms 的短距离上移/淡入，背景直接使用既有缓存磨砂取色，不增加退出等待。

只运行四项页面身份/设置栈纯 JVM 回归与既有四项下一首回归，再生成一个 internal Release 和做必要打包核验；不启动额外设备，不自动写入真实账号。
