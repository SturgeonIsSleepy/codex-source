# 0.6.7 网络与队列修复

接续本地 0.6.6 ytmfix/ytmproxy 未提交修复，整合并修正其代理配置、匹配和重试逻辑。固定用户原签名与内置 NCM 1.1.0，保留三 ABI 通用自用包。

## 行为

- 设置 → 播放设置 → 独立分流：默认开，可关闭。启用后两种引擎的远程音频与预缓存共用绑定非 VPN 网络的 OkHttp 数据源，DNS 也在该网络解析，并禁用 HTTP 系统代理；没有可用直连网络时失败，不自动走 VPN。关闭后新连接跟随系统路由。已建立的音频连接不强制中断。
- YTM 元数据保持独立，空代理地址跟随系统 VPN；也支持 SOCKS5 地址，关闭分流时忽略保存的自定义地址。只配置外部 VPN 客户端的代理端口，不捆绑 VPN 核心，不改系统 VPN 规则。网易云模块 API 和封面等其他请求继续使用原有系统网络，不宣称整个应用全部直连。
- Android VPN 提供者必须允许绕过；始终开启/阻止非 VPN 连接等策略不能由播放器解除。如果 ePlayer 被排除在 VPN 外，可设置 VPN 客户端的本地 SOCKS5 端口供 YTM 使用。参见 [Android allowBypass](https://developer.android.com/reference/android/net/VpnService.Builder#allowBypass()) 和 [Network SocketFactory](https://developer.android.com/reference/android/net/Network#getSocketFactory())。
- 匹配使用歌曲、歌手别名与时长/专辑评分，完全未知歌手不能靠空集合匹配。宣传后缀只按边界清理，不删除名称中的 MV 字母；修正魏→未的错误映射。正常查询无匹配时只补一次曲名查询，依然验证歌手，不能只凭同名选择。
- 可选的歌手别名取自音源 artist/detail，跨语言名不靠硬编码猜测。每轮最多四次额外查询，最多两个并发任务，别名有 24 小时/192 项缓存；YTM 与匹配已有缓存边界保留。失败不切换后端，不做定时重试。
- 搜索结果页在键盘收起时保留正在播放栏；单结果点播合并原有队列，多结果使用整组结果。搜索行高亮当前歌曲。
- 打开播放列表定位当前项，并提供定位按钮。显示顺序来自播放器 Timeline 的真实遍历，操作仍转换成原始媒体项索引，不把显示位置当媒体索引。
- Rust 随机序列按媒体项稳定 UID 保存，预取、自动下一首和手动前后切歌共用；顺序播放不受影响。随机队列拖动调整真实随机遍历，手动下一首优先级保留。
- 保存多位歌手 ID/名字及别名至 MediaItem，旧队列在查看歌手时按需补取信息。
- 设置内部返回预览真实父页面，不再提前显示首页底栏；画面/播放/主题等独立窗口只揭示下层窗口。保存设置父页面滚动位置，返回不重播入场。

## 开销与验证

没有新增网络后台服务、定时器、网络轮询或 VPN 进程。每次音频 HTTP 调用选择一次物理网络，连接池最多保留两个网络；新网络替换旧池时关闭其空闲连接。不能据此声称实际功耗已经降低，手机功耗由用户测量。

本轮用户要求简单测试且不委派子代理，已遵守。32 项定向 JVM 检查通过（匹配/目录夹具/代理解析/导航路径/随机 Timeline）；5 项原保留模拟器组件检查通过（长队列定位、随机显示与点击索引、歌手媒体会话往返、搜索迷你栏、Rust 真实下一首及返回顺序）。未重跑全量回归；没有真实手机 VPN 抓包、YTM→NCM全链路或功耗测试，不将组件检查当作这些行为的实测证明。

按用户要求，自行构建/提交/发布不计算 SHA256，不生成 SUMS。公开交付仅 APK、说明与合成夹具的精简测试结果，不含账号数据、原始 logcat、界面截图、视频、签名私钥或 SDK/AVD。
