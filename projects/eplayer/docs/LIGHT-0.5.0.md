# ePlayer 0.5.0

以 0.4.0 的固定签名交付为基线。用户明确要求保留人物、动效和字体，轻量化仅清理冗余代码、依赖与重复实现，不删除这些资源或播放能力。

## 页面

- 首页：近 7 天听歌统计、继续播放、一个网易云入口。首页不加载推荐接口。
- 网易云：二级页统一放每日推荐、私人 FM、榜单、歌单广场和推荐卡片，进入时才请求数据。
- 曲库：搜索、云端歌单、本地音乐、原魔女歌单、最近播放和下载。
- 设置：底栏最右侧，放账号、音源、音质以及原播放/声音设置。
- 播放器：保留原人物、眼睑与连续动作、原字体和双引擎，新增就近音质选择。
- 歌词：全屏封面氛围背景、大字号当前行、译文、点击定位、手动浏览与恢复跟随，保留播放控制和音质入口。

## 轻量化与兼容

删除 12 个无调用的遗留文件（约 1,217 行）：旧交叉淡入淡出管理器、健康监控、更新器、封面提取器及重复模型；保留现有原生与系统引擎。移除无引用的导航、窗口尺寸类、Media3 UI、Palette、旧歌词 provider 及过时 compileOnly 依赖，并清理对应目录声明。原字体与人物/动画实现不变。

听歌统计只计实际播放，暂停、缓冲与跳转不累计时间。播放服务每 30 秒检查点复用来保存断点位置，不另建定时器；回到首页只读取一次当前快照。统计写本机，不上报。账号 Cookie、音源用户数据、原曲库和队列存储格式保持兼容。

音质选择共用一个组件，支持标准、较高、极高、无损、Hi-Res；切换会更新当前及后续远程队列，保留来源、当前进度与暂停意图，本地文件不重写。账号能获取的音质仍由音源返回。

## 玻璃材质

`ui/glass/LiquidGlass.kt` 将保存的 liquid-glass-model 光学模型移植为原生 AGSL：圆角矩形 SDF、曲面轮廓、Snell 折射、1.46 折射率、3.2 折射强度、1.025 中心放大、局部轻模糊与法线方向反射。使用 Compose GraphicsLayer 重用实际页面的 GPU 显示列表，不逐帧截图或读回位图；文字图标在光学层之上。Android 13 以下使用静态清透材质回退，不把回退称为真实折射。MIT 署名保存在项目及 APK assets。

渲染方法参照 [Android GraphicsLayer 文档](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)；浮动分栏与上方迷你播放器参考 [Apple 的新设计讲解](https://developer.apple.com/videos/play/wwdc2025/284/) 和 [Tab bars 指南](https://developer.apple.com/design/human-interface-guidelines/tab-bars)。
