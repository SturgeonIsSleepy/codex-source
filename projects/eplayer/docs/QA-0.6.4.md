# ePlayer 0.6.4

按本轮要求，只检查本次改动范围，不重跑完整音源、登录、播放引擎与网络回归。

参考用户提供的 YTM 实机视频：队列随手势移动，展开后顶部为紧凑播放栏；视频未显示触点，不推断手指确切起点。应用从封面区域或底部安全区内的队列入口起滑，在原播放器窗口内连续移动独立队列面板，支持下拉收回及列表到顶后的下拉，保留队列滚动位置。没有将播放器变为整页长滚动列表。

整行手势由一个检测器区分：普通点击播放；长按后移动越过阈值只排序，松手提交；原地长按松手进入多选并选中该歌曲；多选时拖动不排序，只正常滚动。不再同时使用长按选择与长按拖动检测器，也不在多选状态显示移动柄。保留更多菜单、全选、批量移除与边缘自动滚动。

角色资源在首页后台预热；已缓存时不等待新的加载状态。弹出队列时保持 AndroidView 已挂载，隐藏画面并停止角色动画，返回时直接恢复同一视图。迷你播放条统一边距、圆角与歌曲信息，主播放按钮使用与文字一致的中性色；底栏页面使用短淡入位移，设置层级和对话页面补充入场过渡。
