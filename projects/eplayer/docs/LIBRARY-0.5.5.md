# ePlayer 0.5.5

曲库每次从其他底栏页进入时默认歌单。只保留服务器歌单中的喜欢列表，移除顶部重复入口；音乐云盘位于列表底部。原来的两首硬编码预设元数据与导入入口移除，已有用户导入文件保留并迁移为普通本地音乐，旧队列文件 URI 保持可用。

用户明确选择：曲库和设置根页返回直接退出到系统，保留底栏页，不跳首页。搜索、发现页和详情按内部层级返回；隐藏的库搜索不再截获其他根页返回。所有底部面板取消半展开停留，一次返回关闭，文字编辑时仍遵循系统键盘层级。继续支持预见式返回。

底部当前播放条新增队列按钮。队列编辑模式可直接移除、长按拖动、边缘滚动排序，并提供无障碍上/下移动作；清空需应用内确认，只影响队列。移动保留当前曲身份和位置；清空会停止 FM 补充，避免空队列又被自动填入。封面和歌曲标题在切歌时短暂淡入/缩放，伊蕾娜 View 与播放控件保持挂载，不增加持续特效。

歌单页的听歌排行默认请求网易 `user/record` 的 `type=0` / `allData`，可切到最近一周 `type=1` / `weekData`。沿用登录态和账号 ID，按服务器顺序排列；score 不是次数，次数仅在接口明确提供正值时显示。权限、登录失效、模块不支持与真正空榜分开显示，不把错误当零记录。入口按需请求，不改变首页的本地统计。

依据：[ncm-api-rs user_record](https://github.com/SPlayer-Dev/ncm-api-rs/blob/main/src/api/user_record.rs)。无真实账号的自动测试只验证响应语义与界面，不能声称已读到用户账号总榜。
