# ePlayer 0.6.12

首页原先把一键点歌标题、筛选、网格行作为 Box 的同级子项，导致它们画在同一位置。现在使用纵向布局，测量标题和筛选的实际高度，再以剩余空间分配卡片；较矮视口或大字体会减少可见行数，保持首页单屏。听歌统计的右侧文字也有明确的宽度约束。

歌手选择页使用56dp圆头像、至少80dp独立行，并支持滚动较长的歌手列表。头像仅为可见行按需请求，复用现有64项/6小时资料缓存；加载失败仍可通过头像占位和姓名选择。歌手搜索列表也采用一致的头像行。

歌手详情的头像、姓名及简介移到顶部、作品搜索和歌曲/专辑切换之前，随现有顶栏展开收起。简介点击可查看全文；列表内不再重复放置同一资料区。

评论提供热度和最新切换。热度调用 `comment/hot` 并保留服务端排名，最新调用 `comment/music`；不会把最近30条在本地按点赞数伪装成全局热度。切换会取消旧加载，并通过请求序号防止旧响应覆盖新排序。

验证：Android17模拟器上的5项定向检查通过，覆盖普通首页、大字体短视口、歌手行头像/触控/选择、实际歌手详情页信息顺序，以及使用本地HTTP夹具验证评论热度/最新路由和返回顺序。手机未连接，没有真实账号评论写入或全量回归，也未测量功耗。保留0.6.11的音频缓存和后台续播修复。

交付原签名、原音源、三ABI自用通用包；不计算SHA256。源码和安装包保存到GitHub后清理本地构建目录，只保留最新APK及共享SDK中的Android17＋KernelSU模拟器。
