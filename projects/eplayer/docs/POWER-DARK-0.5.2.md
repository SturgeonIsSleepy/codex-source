# ePlayer 0.5.2

用户后续调整交付方式：默认仅一个自用通用 APK（`ePlayer-v0.5.2-internal.apk`），包含 ARM64、ARMv7 和 x86_64。普通版只在明确要求时制作，不再另做 ARM64 派生包。下方四包摘要保留为首轮实际交付记录，当前自用通用包无需重构建即可使用。构建与验证入口改为 internal universal，本次仅调整流程，不改变已验收应用字节。Terra high 核验了 internal universal 的选择、启动与证据目录，24 项 ePlayer 脚本检查通过；未为这次流程调整重建应用。

本轮以 0.5.0 为基线，按用户要求去除液态玻璃并完善深色模式，保留人物、动效、字体、双引擎和现有音乐功能。每天开发 agent 的 0.5.1 核心整合候选独立维护，本分支没有合入该候选。

悬浮底栏和迷你播放器改为不透明材质，删除折射着色器与页面图层捕获。深色模式统一背景、浮层、文字、图标和歌词对比度；天空按主题预生成并缓存，原人物图层和字体保持不变。

人物被其他页面遮挡、隐藏或离开窗口时取消绘制回调。能量采样仅在可见动画需要时短时启用，PCM 原始音频照常传输。暂停的原生引擎降低空轮询频率，播放命令仍立即唤醒；播放中的轮询与人物动作节奏保留。队列与声音设置延迟更新，进度保持独立刷新。

## 验证与交付

本轮采用精简验证：JVM 能量采样契约、13 项有针对性的 Android 检查，以及最终固定签名 APK 的最小启动与深色界面验收。历史完整功能验收见 [0.5.0 记录](LIGHT-0.5.0.md)，不将历史结果计入本轮新通过项。首轮源码 `e1c0bcf42f477b2adf12a678fda1ecf05720389a` / [CI 40866708406](https://github.com/SturgeonIsSleepy/codex-source/actions/runs/40866708406) 构建和 13 项针对性检查通过，本地 API 36 隔离模拟器同样 13 项通过；31 项仓库脚本与 2 项能量租约 JVM 检查通过。但 Terra high 实际查看夜间截图，发现歌名、时间和默认图标继承了黑色，原调色板对比度断言未覆盖这个缺陷。这份候选不交付；已在主题根部补充内容颜色继承，并加强实际控件像素检查，修复源码 `3565e405dbf7ea0a750567a0b6c4d67554243f5b` 的补强深色检查已在本地 API 36 模拟器通过（1 项），Terra high 实际查看截图，确认歌名、歌手、时间和启用的头栏图标清晰可读。[CI 40871670905](https://github.com/SturgeonIsSleepy/codex-source/actions/runs/40871670905) 已完整成功：JVM 任务、普通/自用 R8 构建、13 项针对性 Android 检查（45.136 秒）与普通 x86_64 R8 冷启动（1874ms）通过。最终本地固定签名的普通/自用通用包分别通过深色冷启动、系统引擎播放后暂停及位置稳定检查（各 1 项），并实际查看暂停截图确认歌名、时间与启用图标清晰可读。内部版通过覆盖安装，未清除已有数据。整个过程仅操作 API 36 x86_64 隔离模拟器。

后续测试、Computer Use 和网页信息读取按用户指定交给 GPT-6.1 Terra，推理强度 high；主 agent 负责实现、整合与交付。独立的 CI/下载任务、设备检查和交付准备并行推进；同一模拟器只由一个 agent 操作，输入依赖就绪后再进行签名与最终验收。本轮不接触用户手机的登录数据。功耗由用户测量，模拟器结果不代表手机功耗达标。

普通版不含音源，自用版保留用户指定的 NCM 1.1.0 模块；沿用原本地签名。ARM64 派生包仅删去其他 ABI，保留 DEX、清单、资产和 ARM64 库，运行验收与通用包区分记录。原始性能报告和签名私钥不上传。
