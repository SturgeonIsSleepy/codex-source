# ePlayer 0.6.1

底部播放条/导航由 64+66 dp 缩至 50+54 dp，相应减少页面底部留白。列表封面 64→48 dp、曲目封面 44→40 dp，正文和标题整体缩小；保留可操作区域。设置移除账号行，剩余入口使用统一 48 dp 最小行高和相同间距；账号仍由头像直接进入。

没有图片的流派/分类显示本地绘制的渐变与图案封面，避免空白图片槽，不额外为每个分类发请求。它们是分类插画，不假冒服务端唱片封面。

模糊 Slider 取消离散步长，保存真实 Float；CPU 缓存处理用相邻半径结果的连续插值，保留暂停后的实际小数值。调节提供限频触感反馈，并显示小预览；没有增加常驻 GPU 模糊。歌词开场仅在 360 ms 期间使用封面放大、瞬态模糊和磨砂/正文淡入，动画结束移除该层。返回仍即时提交，不等待额外退出动画。

手动下一首附独立请求令牌，不改变媒体 ID 或随机开关。系统引擎将尚未播放的手动请求固定到 ExoPlayer 随机遍历的当前项之后；原生引擎在自动结束、手动 Next 与预缓存中优先选择请求，并在进入该项后消费令牌。连续点播保持列表下一位的顺序，删除/重排后按项追踪；切换引擎保留已消费标记。随机开关提供高亮、状态点与明确的无障碍状态。队列重建时清理失效请求，不拦截合法 Stop。

播放器竖屏调整为封面/角色在上、歌名和歌手在下、随机/上一首/播放/下一首/循环同一控制行。保留人物动作、自选背景、音质、歌词、播放队列与评论。
