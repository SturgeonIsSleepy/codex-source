# ePlayer 0.5.3

浅色采用带紫调的纸白，深色改为柔和灰紫。保留完整文楷、伊蕾娜人物和动作，只用页标题的一处星芒及统一的紫色强调《魔女之旅》元素。

当前歌曲与最底部导航共用一个连续圆角面板，上层播放、下层导航，只以细分隔线区分。点击播放按钮不打开大播放器，点击歌名才展开。

播放页只在原蓝天所在的人物区域放置方形歌曲封面，伊蕾娜在封面前景，身体和腿可伸出封面；其余页面底色保持干净。封面按 512px 缓存解码，歌词页按 320px 与静态主题渐变；不使用持续模糊或页面捕获。伊蕾娜画布使用原有修复图和动作，透明背景模式只略过旧天空，不重绘人物。没有封面时使用中性主题底板，不用参考截图伪装为专辑。

全屏播放、歌词、云端详情与播放设置使用同一个预见式返回容器；确认对话框在自己的窗口内注册返回进度，取消手势恢复原页，完成才返回且不执行确认动作。根页返回预览首页或曲库；层级详情和声音设置显示上一级数据。上下文菜单统一为支持原生预测返回的底部面板，队列、音质、评论等保留 Material3 的内置行为。首页没有内部返回层级时交给系统执行返回桌面动画。

实现依据：[Compose 预测返回](https://developer.android.com/develop/ui/compose/system/predictive-back-setup)、[PredictiveBackHandler](https://developer.android.com/reference/kotlin/androidx/activity/compose/PredictiveBackHandler.composable)。取消流程不会改变登录、队列或执行删除/退出账号等确认操作。

本轮只交付内置用户指定音源的自用通用包。不另外制作普通版或交付独立 ARM64 包。测试与网页读取由 GPT-6.1 Terra high 执行，CI、下载、设备检查与交付准备并行，真实手机功耗仍由用户测量。
