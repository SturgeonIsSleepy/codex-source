# ePlayer 0.6.0

按用户提供的 YouTube Music 截图重排：首页、探索、媒体库三栏，根页返回仍退出并保留当前栏。头像进入账号菜单，设置、历史和下载入口从此进入。首页从统计到一键点歌，搜索为标题栏图标展开。探索按需加载新发行、排行榜、分类歌单及推荐；未增加首页算法轮询。

视觉改为固定中性浅/深色、矩形独立标签、扁平列表及贴底播放条。默认深色，可选择浅色/系统；不使用动态配色或壁纸生成调色。Material3 只保留基础控件实现，页面不再采用 Material You 的紫色圆角卡片风格。保留原有角色、动作、字体及双音频引擎。

移除随包 MTZ 壁纸。画面设置可导入播放器背景并移除；仅复制到应用专用目录，25 MB 输入上限，采样至最长边不超过 1600 px，压缩 WebP。原图不改动、不删除，不要求永久相册权限。背景用于播放页及角色后方，普通专辑封面仍保持歌曲信息。正文区域覆盖固定底色以保持可读性，无动态模糊。

一键点歌支持歌手/歌单/专辑/单曲，来自账号歌单、最近听歌和已选择的漫游种子，也可搜索指定新种子。先播放种子对应曲目/列表，再通过已核实的 ncm-api-rs simi/song 补充相似歌曲；无相似结果时保留现有队列，不伪装成另一种推荐。旧请求通过代次隔离，暂停时不补充，清空会取消补充。

播放队列支持多选、全选和批量移除，连续范围按倒序合并删除；全选删除走停止/清空逻辑。歌单支持多选、全选、播放所选和加入队列；自有歌单可确认后批量移除。全选通过完整 trackIds 获取未加载歌曲，不局限 200 首；批量播放时按需取元数据。自有喜欢歌单沿用逐首取消喜欢能力。
