# ePlayer 0.5.4

歌词使用 YRC、增强 LRC 或 TTML 提供的真实词起止时间。逐词扫色采用同一文字布局的字形裁剪，可跨行、处理 RTL 与代理对；没有词时间的 LRC 继续逐行，绝不均分伪造词时间。播放页的封面/前景伊蕾娜布局保持 0.5.3 的形式。

TTML 的 agent 用于左右对话布局，背景声 `x-bg` 与其翻译/音译独立保留，角色 `type=other` 不被称为另一位真实歌手。已知声音区间之间的空档、显式空行和已知尾奏显示三点浮动；按播放时钟运动，暂停固定，隐藏或后台停止精细刷新。

歌词背景从歌曲封面低分辨率取色，72px 离线三次盒模糊并加明暗材质；每张封面/模式只生成一次，最多缓存四张。不逐帧模糊，也不恢复光学玻璃。参考用户图的大字号、顶部信息与留白，正文不叠加说明标签。

音源返回保留 `yrc/ytlrc/yromalrc`，私有缓存版本升级兼容旧 original/translated JSON。先显示缓存/音源歌词，再异步补充公开角色 TTML；网易曲目按受控数字 ID 查询 AMLL 数据库，若声明 ncmMusicId 必须匹配。GitHub 原始来源有界超时，网络失败可尝试公开 CDN，失败保留已有词/行数据。缓存避免每次开页重请求，旧缓存失败仍保留。

花譜《花女》网易 ID `1501450521` 的匿名网易响应只有逐行歌词；[对应 AMLL 文件](https://github.com/amll-dev/amll-ttml-db/blob/main/ncm-lyrics/1501450521.ttml) 含真实逐词、翻译、音译与 v1/v2（62/18行）角色。TTML 与普通 LRC 的部分起始时间差约 0.03–0.42 秒且断句不同，不强行按 LRC 校正，也不据此宣称音轨版本永远一致。实际同步待设备验证。

[AMLL 格式说明](https://amll.dev/en/guides/lyric/formats)、[TTML 规范](https://github.com/amll-dev/amll-ttml-db/blob/main/instructions/ttml-specification-en.md) 和[共享说明](https://github.com/amll-dev/amll-ttml-db#共享协议) 为解析依据。贡献者自编部分按 CC0，外来数据仍遵守原提供方协议；不将整首歌词版权表述为 CC0。应用不捆绑歌曲 TTML，下载内容只缓存在本机；歌词选项提供来源链接。

主 agent 编写实现与测试，GPT-6.1 Terra high 执行资料核实、检查、CI、界面验证。默认仅自用通用包，签名和用户指定内置音源沿用，不触碰真实账号或实机。
