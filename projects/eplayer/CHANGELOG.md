# ePlayer 变更

## 0.6.7

- 可关闭音频/YTM独立分流，无新增服务或轮询；严格 VPN 策略下不回退到隧道播放。
- 基于别名、时长、专辑评分匹配歌曲，限制补查次数，保留失败不换推荐后端。
- 搜索结果保留播放栏，单结果点播保留原队列；队列支持自动定位及定位按钮。
- 多歌手及别名穿过媒体会话，设置返回预览实际父页面。
- Rust 使用固定随机遍历，预缓存、自动切歌与显示一致，随机队列仍可编辑。
- 定向32项JVM与5项模拟器组件检查通过，未做全量回归或真实VPN/功耗测试。

## 0.3.2（组合验收中）

- 音乐换到不同采样率时，向新原生输出重新应用保存的 EQ/空间参数；修复前后都有真实合成音频幅度回归。
- 联网缓冲时暂停，下载完成保持静音；主动恢复后启动待播放音频，验证原生进度、时长与幅度。
- 声音手记支持频率、增益、Q 的同组编辑；取消/非法输入不改设置，与 AutoEQ 共用数值范围校验。
- 播放缓存从服务中独立，远端 open 时才初始化；本地导入不扫描流媒体缓存。删除未使用的危险释放/递归删除入口。
- 删除 Android 层无调用的 USB 独占注册/硬件控制桥接，保留只读回归探针及普通系统音频路由。
- 引擎替换先恢复队列/位置/播放请求再交接媒体会话；合法框架Stop仍可停止原生输出。
- 下载读取遵守协程取消，关闭输出并清理本次未完成临时文件；成功文件保留，未宣称跨曲下载所有权已全部解决。
- 真实 EQ 检查增加三个完整生命周期与跨采样率换曲；增加流式缓冲暂停、缓存旁路、离线重读及下载取消检查。

分项及组合37项设备回归已通过（36通过/1登录跳过）；主线R8/确切交付尚未执行。引擎交接空状态已通过同一框架状态断言的红绿回归，合法框架Stop仍可停止原生音频；不宣称所有历史停止问题根因已经消失。人物/表情/动画素材未改；没有捆绑歌曲录音。
